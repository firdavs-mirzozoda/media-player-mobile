# Media Player — мобильная версия (React Native / Expo)

Android-версия настольного плеера: поиск и просмотр видео с YouTube, Rutube, VK и своих сайтов
с JSON API, смена качества без остановки видео, скачивание, распознавание песни по звуку и
поиск фильма по кадру. Интерфейс на русском и английском.

Подробно о стеке — в [TECHNOLOGIES.md](TECHNOLOGIES.md).

## Запуск

```bash
npm install                # заодно применит патч к expo-video (patch-package)
npx expo run:android       # dev-сборка на телефоне/эмуляторе (нужен Android Studio)
```

Expo Go **не подойдёт** — в приложении свои нативные модули, нужна dev-сборка.

Готовый APK без Metro:

```bash
npx expo prebuild -p android
cd android && ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
# → android/app/build/outputs/apk/release/app-release.apk
```

Папки `android/` и `ios/` генерируются (`npx expo prebuild`) и в репозиторий не входят —
настройки живут в `app.json`. На Windows собирайте из короткого пути (например `C:\mp`):
иначе сборка нативных модулей упирается в лимит 260 символов на путь.

## Что умеет

| | Как устроено |
|---|---|
| YouTube | InnerTube API (`src/api/youtube.js`): поиск, HLS/DASH до 1080p, скачивание любого качества — дорожки склеиваются на телефоне |
| Rutube | JSON API → HLS; скачивание — склейка сегментов и пересборка в mp4 |
| VK Видео | веб-эндпоинты vk.com без токена, mp4 до 1080p |
| Свои сайты | JSON API: шаблон URL с `{q}`, `{page}`, `{offset}`, `{token}`; `id` — прямая ссылка на .mp4/.m3u8 |
| Качество | меняется без остановки видео (`modules/media-muxer`, исключение вариантов в ExoPlayer) |
| Песня рядом | микрофон → свой отпечаток в формате Shazam (`src/api/shazamSignature.js`) |
| Фильм по кадру | скриншот, видео или ссылка → обратный поиск в Яндекс Картинках |

## Жесты плеера

- тап — показать/скрыть управление, двойной тап слева/справа — ±10 с;
- смахнуть видео вниз — свернуть в плавающее окно;
- плавающее окно можно двигать по экрану, оно прилипает к краю; смахнуть за край — закрыть;
- тап по окну — развернуть обратно. Звук продолжает играть в фоне.
