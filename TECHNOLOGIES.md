# Технологии проекта

Медиаплеер, который ищет и воспроизводит видео с YouTube, Rutube и VK, умеет скачивать их,
узнавать песню по звуку и находить фильм по кадру. Есть две версии: настольная (Electron)
и мобильная (Android, React Native).

---

## Настольная версия (Electron)

| Что | Зачем |
|---|---|
| **Electron 39** | оболочка приложения для Windows/macOS: главный процесс на Node.js + окно на Chromium |
| **electron-vite 5**, **Vite 7** | сборка main / preload / renderer, горячая перезагрузка при разработке |
| **Vue 3.5** (Composition API) | интерфейс: поиск, плеер, загрузки, настройки |
| **hls.js** | воспроизведение HLS; качество переключается через `nextLevel` — без остановки видео |
| **yt-dlp** + **Deno** | получение потоков и списка качеств (`yt-dlp -J`), Deno нужен yt-dlp для JS-проверок YouTube |
| **ffmpeg** | склейка видео- и аудиодорожек при скачивании |
| **@mdi/js** + **@jamescoyle/vue-icon** | иконки Material Design в виде SVG-путей |
| **electron-builder** | сборка установщика |
| **ESLint**, **Prettier** | проверка и форматирование кода |

Связь окна с Node.js — через `preload` (`contextBridge`) и `ipcMain.handle`: окно не имеет
прямого доступа к файлам и процессам.

## Мобильная версия (Android)

### Основа

| Что | Зачем |

| **React 19** | компоненты и состояние (hooks, `useSyncExternalStore`, Context) |
| **Expo SDK 58** | готовые нативные модули и сборка через Gradle |
| **expo-video** (внутри — ExoPlayer / AndroidX Media3 1.9) | плеер: HLS, DASH, mp4, фоновое воспроизведение, картинка-в-картинке |
| **expo-audio** | запись с микрофона (16 кГц, моно) для распознавания песни |
| **expo-file-system**, **expo-media-library** | скачивание файлов и сохранение в галерею |
| **expo-image-picker**, **expo-clipboard** | выбор скриншота/видео из галереи, чтение ссылки из буфера |
| **AsyncStorage** | история поиска, настройки, тема, язык, выбранное качество |
| **react-native-safe-area-context**, **react-native-svg** | отступы под вырез экрана, SVG-иконки |
| **patch-package** | правка исходников expo-video (см. ниже) |

### Свой нативный модуль на Kotlin (`modules/media-muxer`)

Там, где JavaScript не справляется, работает собственный Expo-модуль на Kotlin:

- **склейка дорожек** (`MediaExtractor` + `MediaMuxer`) — видео и аудио YouTube скачиваются
  отдельно и собираются в один mp4, как это делает ffmpeg на компьютере;
- **пересборка HLS → mp4** — сегменты MPEG-TS (Rutube) склеиваются и перепаковываются без
  перекодирования; аудио AAC разбивается на отдельные кадры, иначе в файле пропадает звук;
- **декодирование звука в PCM 16 кГц** (`MediaCodec`) — вход для распознавания песни;
- **кадр из видео** (`MediaMetadataRetriever`) — для поиска фильма по кадру, в том числе по ссылке;
- **смена качества без остановки** — модуль обращается к ExoPlayer и исключает лишние варианты
  потока из адаптивного выбора (`ExoTrackSelection.excludeTrack`), поэтому новое качество
  приходит со следующим сегментом, а не через перезагрузку видео.

expo-video собирается из исходников с небольшим патчем (`patches/expo-video+58.0.11.patch`):
запросы плейлистов и сегментов из локально созданного манифеста получают те же HTTP-заголовки,
что и сам источник.

### Источники видео

- **YouTube** — внутренний API InnerTube (тот же, что у официальных приложений): поиск,
  потоки HLS/DASH, несколько клиентов на случай отказа, скачивание кусками по 4 МБ.
- **Rutube** — открытый JSON API и HLS-потоки.
- **VK Видео** — веб-эндпоинты vk.com без токена (ответы в кодировке windows-1251).
- **Свои сайты** — любой сайт с JSON API: адрес поиска с `{q}` и поля ответа задаются
  в настройках.

### Возможности и как они сделаны

- **Распознавание песни** — свой порт алгоритма отпечатков Shazam (окно Ханна, БПФ на 2048
  точек, поиск пиков по частотным полосам, бинарная подпись + CRC32) и запрос к сервису
  распознавания Shazam. Ключи API не нужны.
- **Фильм по кадру** — обратный поиск картинки в Яндекс Картинках; для ссылок
  (Instagram, YouTube, TikTok, VK, Rutube) кадры берутся из превью страницы или из самого видео.
- **Очередь загрузок** — хранилище вне React (`useSyncExternalStore`), до двух загрузок
  одновременно; готовые файлы качаются параллельными Range-запросами с повтором оборванных
  кусков.
- **Плеер как в YouTube** — жест вниз сворачивает видео (`PanResponder` + `Animated`),
  свёрнутое окно можно таскать по экрану, оно прилипает к краю и закрывается смахиванием.
- **Два языка** — русский и английский, свой небольшой модуль (`src/i18n.js`) со словарями и
  React Context; язык меняется в настройках сразу, без перезапуска.
- **Темы** — тёмная и светлая, цвета в одном файле (`src/theme.js`).

### Сборка

- Gradle + Android SDK / NDK, Node.js 20+ (собиралось на Node 26).
- Релизный APK под `arm64-v8a`, код сжимается R8.
- Проект собирается из короткого пути (`C:\mp`) — из-за ограничения Windows в 260 символов
  на путь к файлу при сборке нативных модулей.

## Структура

```
src/                         настольная версия
  main/                      главный процесс Electron (yt-dlp, ffmpeg, IPC)
  preload/                   мост между окном и Node.js
  renderer/                  интерфейс на Vue
mobile/                      мобильная версия
  App.js                     главный экран, поиск, плеер, загрузки
  src/api/                   YouTube, Rutube, VK, загрузки, распознавание, поиск фильма
  src/components/            плеер, карточки, меню качества, настройки
  src/i18n.js                переводы
  src/theme.js               цвета
  modules/media-muxer/       нативный модуль на Kotlin
  patches/                   патч для expo-video
```
